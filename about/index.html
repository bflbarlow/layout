Layout v0.4.0

A page layout editor built with HTML, CSS & JavaScript. No dependencies, no build step. Design multi-page documents directly in the browser.

Features

  • Rich TextFull rich-text editing with bold, italic, underline, strikethrough, superscript/subscript, font family, size, weight, and color — all with inline formatting support.
  • Text Box StylesFill, stroke, opacity, corner radius, and rotation per text box. Vertical alignment, overflow mode, column count, drop caps, and hyphenation.
  • Vector LinesLine tool with stroke color, width, and opacity.
  • Image InsertUpload images with automatic sizing and aspect-ratio preservation.
  • Multi-PageCreate, reorder, and delete pages with thumbnail navigation. Per-page dimensions with Letter and A4 presets.
  • LayersEvery element has a unique z-height (no two share a rank) — reorder by dragging a row, with Bring Forward / Send Backward, or by typing a z value; name elements (double-click the name in the panel); and toggle visibility.
  • Undo/Redo50-step history with Ctrl+Z / Ctrl+Shift+Z.
  • Find & ReplaceSearch and replace text across the document (Ctrl+F).
  • Project FilesSave and import projects as .json files. Auto-save to localStorage.
  • ExportExport as standalone HTML with embedded fonts, or print to PDF.
  • Canvas ControlsZoom, pan (middle- or right-button drag), grid overlay, and rulers. Pinch-to-zoom and two-finger trackpad panning.
  • Dark ModeSystem-aware light/dark theme with manual toggle.

Quick Start

Creating Elements

Select a tool from the toolbar (V for Select, T for Text, R for Rectangle, C for Circle, L for Line), then click or drag on the canvas to create elements.

Editing Elements

Click to select, drag to move. Drag the resize handles on corners and edges. Use the Properties panel to adjust position, size, fill, stroke, and text style.

Managing Pages

Use the Pages sidebar to add new pages, click thumbnails to switch, and hover thumbnails to reveal the delete button.

Tip: Use the Layers panel to reorder elements. Elements at the top of the list appear in front.

Technical Details

  • Framework:  Vanilla JavaScript (ES5-compatible), no dependencies
  • Rendering:  DOM-based elements positioned on a canvas page with zoom/pan transforms
  • State:  Centralized state object per-page with undo/redo (50 steps)
  • Persistence:  localStorage auto-save + JSON project file export/import
  • Theme:  System-aware light/dark theme with manual toggle and no-flash detection
  • Canvas:  Configurable page size (default 850 × 1100 px, US Letter aspect ratio)
  • Export:  Standalone HTML with inline CSS and Google Fonts embedding; PDF via browser print
  • Rich Text:  contentEditable-based editor with saved selection, inline formatting, and toolbar
